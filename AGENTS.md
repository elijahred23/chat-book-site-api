# Repository guidance

## Scope and layout

- This repository is a single deployable application: a React 18/Vite client in `src/` and an Express API in `api/`.
- Treat `package.json`, `vite.config.js`, `api/package.json`, and the source tree as authoritative. The current `README.md` describes an older architecture and contains paths that do not exist here.
- `dist/` is generated by Vite. `node_modules/`, `api/node_modules/`, `api/logs/`, `var/uploads/`, and `*.log` files are generated or runtime state; do not hand-edit or commit them.
- Never read, expose, or commit values from `api/.env`, `secrets/`, or `var/secrets/`. Document new configuration in `api/.env-template` with empty values.

## Local workflow

- Install frontend dependencies with `npm ci` and API dependencies with `npm ci --prefix api`.
- Run the client with `npm run dev` (Vite on port 3006) and the API with `npm start` (Express on port 8080).
- `docker compose up --build` runs both services, with the Compose frontend exposed on port 5174.
- Production is a single container: Vite builds `dist/`, then Express serves those static files and the client-side routing fallback.

## Change discipline

- Keep changes scoped. Do not reformat unrelated files or modify generated output.
- Preserve the existing ES module style and local formatting of files being changed.
- When a feature crosses the HTTP boundary, update both the API contract and every client caller in the same change.
- Prefer extending existing shared components and utilities over introducing a second pattern for the same behavior.

## Validation

- For client changes, run `npm run lint` and `npm run build`.
- For API changes, at minimum run `node --check` on each changed API JavaScript file and exercise affected endpoints with the server running.
- There is currently no automated test suite. `npm test --prefix api` is a placeholder that always fails; do not report it as a product failure.
- In the handoff, state which checks ran and call out any checks that require API credentials or external services.
